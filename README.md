Установка и запуск

Клонировать репозиторий:

bash
git clone https://github.com/ТВОЙ_USERNAME/zaloghub-todo.git


Перейти в папку:

bash
cd zaloghub-todo


Установить зависимости:

bash
npm install


Запустить приложение:

bash
npm run dev


Собрать проект:

bash
npm run build
