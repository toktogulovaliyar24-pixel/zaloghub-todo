ZalogHub Todo List

Тестовое задание на позицию Junior Frontend Developer.

О проекте
Простое приложение для управления списком задач.

Используемые технологии
React
TypeScript
Vite
CSS
LocalStorage

Возможности
Добавление задач
Выполнение и отмена выполнения задач
Удаление задач
Фильтрация: все, активные, выполненные
Сохранение задач в LocalStorage
Запрет добавления пустых задач
Добавление задач клавишей Enter
Адаптивный интерфейс

Установка и запуск
Клонировать репозиторий:
bash
git clone https://github.com/toktogulovaliyar24-pixel/zaloghub-todo.git

Перейти в папку проекта:
bash
cd zaloghub-todo

Установить зависимости:
bash
npm install

Запустить локально:
bash
npm run dev

Собрать проект:
bash
npm run build
